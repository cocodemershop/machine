# Gipsy Fortune

Der Wahrsage-Automat mit Pablo the Gipsy und Esmeralda. Auf Deutsch, Englisch und Spanisch.
Läuft komplett im Browser: kein Server, keine Cookies, kein Tracking.

## So geht die Seite auf GitHub online

1. Auf github.com einloggen und oben rechts auf **+ → New repository** klicken.
2. Name eingeben, z. B. `gipsy-fortune`, **Public** wählen und **Create repository** klicken.
3. Auf der leeren Repository-Seite auf **uploading an existing file** klicken.
4. **Alle Dateien aus diesem Ordner** in das Feld ziehen (index.html, manifest.webmanifest, sw.js, die drei Icons, README.md).
   Die versteckte Datei `.nojekyll` darf fehlen, sie ist nur ein Beschleuniger.
5. Unten auf **Commit changes** klicken.
6. Oben auf **Settings**, links auf **Pages**.
   Unter *Build and deployment*: Source **Deploy from a branch**, Branch **main**, Ordner **/ (root)**, dann **Save**.
7. 1 bis 2 Minuten warten und die Seite neu laden. Oben erscheint der Link:
   `https://DEIN-NAME.github.io/gipsy-fortune/`

Wichtig: Der Link `github.com/...` zeigt nur den Quelltext. Die echte Seite ist die Adresse mit **github.io**.

## Aufs iPhone als App

Den github.io-Link in Safari öffnen, auf **Teilen → Zum Home-Bildschirm** tippen.
Pablo liegt dann als App mit eigenem Icon auf dem iPhone und läuft auch offline.

## Später etwas ändern

`index.html` auf GitHub öffnen, auf den Stift klicken oder die neue Datei hochladen.
Danach in `sw.js` die Zeile `VERSION` um eins hochzählen, damit Handys die neue Fassung laden.
